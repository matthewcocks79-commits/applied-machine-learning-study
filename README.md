\# Applied Machine Learning with Python



\## About This Repository



This repository documents my independent study of machine learning using Python and JupyterLab.



The aim is to develop my understanding of machine-learning algorithms, their mathematical foundations and their practical applications.



Each project combines:



\- Explanations of important machine-learning concepts.

\- Python code with detailed commentary.

\- Data exploration and visualisation.

\- Model training and evaluation.

\- Reflection on the results and limitations.



\## Projects



\### 01 — Credit Card Fraud Detection



My first project investigates binary classification using Logistic Regression.



The project explores class imbalance, feature scaling, classification thresholds, precision, recall, F1 score and cross-validation.



\[Credit Card Fraud Detection Project](01\_credit\_card\_fraud/)



\## Software



The projects use Python, JupyterLab, pandas, NumPy, Matplotlib and scikit-learn.



\## Learning Resources and Attribution



My studies are informed by \*Machine Learning Projects with Python\* by Adams Anderson, alongside other learning resources and official Python documentation.
